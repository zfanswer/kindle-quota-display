# 中文墨水屏布局

标题为“Agent 额度”，每个Provider为独立卡片，包含产品名、状态、完整数据更新时间和各真实额度窗口。窗口显示剩余比例、进度条及固定重置日期时刻。

布局针对1072×1448竖屏、16灰阶。两窗口与三窗口采用不同垂直间距，无数据仍保留对应Provider卡片。简体中文由服务端字体渲染成PNG，Kindle无需安装字体。

不展示实时钟、冻结的重置倒计时、相对年龄或页脚刷新说明。旧图片停留时不会动态改变，卡片内绝对采样时间是判断其新鲜度的依据。未知重置时间不猜测，窗口之间不合成为一个“总体可用额度”。

五种[合成预览](validation.md)由scripts/render-previews.py生成。新增Provider或分辨率需要重新评估单屏容量/分页，同时更新PNG校验和设备验收。

固定启动占位图复用同一标题、两张Provider卡片与排版。卡片状态为“刷新中”，正文“正在刷新quota信息”，不显示额度数字或历史时间；有效成功缓存优先，无缓存才使用它。
