# 设备验收模板

复制为忽略的 `docs/acceptance.local.md` 后填写。不要把实际IP、账户信息、原始日志或设备备份提交到公开仓库；公开报告只保留脱敏结果。

| 场景 | 预期 | 结果及本地证据 |
| --- | --- | --- |
| 离线检查 | 全部通过，合成预览正常 | |
| 真实目标源 | 与CodexBar相同账户/窗口/值 | |
| 无额度源 | 通用暂无数据，不阻塞其他源 | |
| Docker / LAN / PNG | 服务可达，中文及规格正确 | |
| 定时采集 | ≥三轮，不重叠、时间可信 | |
| USB安装 | 目标正确、备份、hash、安全推出 | |
| 手工绘图 | 方向/文字/卡片/时间正确 | |
| 启动缓存占位 | 最近成功PNG优先；无有效缓存时卡片式刷新占位；随后新图替换，旧额度快照不用 | |
| RTC短期 | ≥三帧、两次自动返回 | |
| RTC一小时 | 不中断、满足轮次/时长，失败如实记录 | |
| 全屏刷新 | ≥30分钟触发，残影可接受 | |
| 停止 / 提前唤醒 | 状态恢复、可阅读、不误伤其他alarm | |
| 网络失败 / 恢复 | 保留旧图、恢复后继续 | |
| 数据过期 | 服务在线但停采集，≥10分钟状态变化 | |
| DHCP / 换网 | 缓存失效后发现、地址更新、图片恢复 | |
| 非支持子网 | 不越界扫描，固定IP/主机名恢复 | |
| 回滚 | 停job/服务，恢复设备项目文件 | |
